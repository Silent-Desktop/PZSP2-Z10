## Temat projektu
Celem projektu było stworzenie dla klienta interaktywnego notatnika porównującego działanie modelu Mixed Integer Programming (AMPL) z działaniem własnego algorytmu inspirowanego naturą (ewolucyjnego).  
## Uruchomienie narzędzia
Potrzebny jest menedżer pakietów `uv` — `pip install uv`.  
Należy wykonać `uv sync` i otworzyć `NetworkEvolution.ipynb`.  
W Jupyter Notebook wybrać stworzony `.venv` (pod nazwą `net_opt`) jako kernel (prawy górny róg).
